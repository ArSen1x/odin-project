# The Odin Project: Node.js Course
Compilation of projects and exercises completed throughout The Odin Project Node.js curriculum. This is an exploratory sub course as I take my **Flyrank AI Internship** under the track **AI Backend Engineering**.

---

## Branch Breakdown

Each branch in this repository represents a specific section or project module in the course:

* **`main`**: The primary branch containing repository overview.
* **`intro-to-nodejs`**: Basics of Node.js, core HTTP modules, event loops, and simple static web servers.
* **`project-orms`**: Working with databases using Object-Relational Mappers (ORMs/ODMs) like Prisma or Mongoose.
* **`project-inventory-app`**: Using Express framework for making a basic inventory app
* **`project-authentication`**: Implementing user authentication, session management, password hashing, and Passport.js.
* **`project-api`**: Designing and building RESTful APIs, handling JSON requests/responses, and managing CORS.
* **`project-testing-express`**: Unit and integration testing for Express routes and controllers using frameworks like Jest and Supertest.
* **`full-stack-projects`**: Mini full-stack applications integrating Node/Express backends with frontend interfaces.
* **`final-project-odin`**: The final capstone project combining all concepts learned throughout the Node.js path.
